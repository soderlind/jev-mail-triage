# Local gate before Jev

Instead of sending every new message to Jev, a local gate runs first and decides only confident cases. Its checks run in a fixed order: authenticated allowlist and known correspondents, allowed languages, near-duplicates of the user's junk, then a hashed-token Bayes filter. Everything uncertain goes to Jev. We chose hashed word statistics and MinHash signatures over embeddings or retrieval (RAG): they need no model download, store no readable text, and are easy to retrain and explain. The cost is weaker generalisation to new campaigns, which Jev still covers. The gate starts in shadow mode and must be switched to enforce explicitly. Local verdicts are recorded as extreme scores with model version `local-gate`, so stored decisions replay through the same policy. They are never fed back as training data. A message the user moves back from the review folder is recognised by fingerprint and left alone, whatever the gate mode.
